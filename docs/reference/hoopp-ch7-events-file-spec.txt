=================== SHEET: Summary ===================
2.    BUSINESS OBJECTIVE
The purpose of the Events interface is to provide the required information about employees to effectively 
administer the pension plan in the Morneau Shepell system.
Information requirements include:
    •	Member identification field (SIN)
    •	Information pertaining to the administration of the pension plan, such as contributions, service amount, 
	employment type, leave information, termination details, etc.
3.    SELECTION MODE
The file is a change only file containing full records for all members that meet the selection criteria outlined in
the section “Selection Logic”.
4.    SELECTION LOGIC
Employees corresponding to the following criteria are to be included in the file:
    •	Any active employee whose death is reported
    •	Any active employee who is retiring
    •	Any active employee whose employment is being terminated
    •	Any pensioner who has re-enrolled and subsequently resumes pension 
5.    FILES SUPPORTED
The interface is defined based on a standard format provided within this document.
6.    FILE DETAILS
    •	Must be encoded in ANSI format
    •	Provides data delimited by a comma
    •	Contains a header (see tab "Header")
    •	Has a ".csv" extension
    •	Is sorted by Social Insurance Number (key identifier), therefore an authorization must be provided.
    •	Will follow the order of the fields specified in the "Events File Layout" which is relevant for administration purposes.
    •	Will be available on the Employer Portal but will have to be manually populated by the employer
    •	Once populated and saved, must respect the "File Details" and "Supported Data Types" outlined in this document.
7.    SUPPORTED DATA TYPES
The following is the list of supported data types for the Events file:
    •	Date format will be MMDDYYYY
    •	Alphanumeric fields supported values range is from A to Z and 0 to 9
    •	Character fields supported values range is from A to Z and 0 to 9 and also include all special characters
    •	Codes provided need to be listed in the "Tables of Codes" section
    •	There are no left padded zeros for numerical values
    •	Decimal symbol is the period (.) symbol
8.    MULTIPLE LINES
    •	None
9.    DATA INTEGRITY
    •	Validations will be covered in a separate Chapter 7 document.
10.    FILE TRANSMISSION DETAILS
    •	The Events data interface files are submitted and processed through the Employer Portal, under the processes 
	Termination, Retirement - Final Data or Pre-Retirement Death.
11.    FILE TRANSMISSION FREQUENCY
    •	Adhoc; in-year
12.    ADDITIONAL ASSUMPTIONS AND COMMENTS
    •	The initial layout is based on a standard layout and is subject to changes until the plan analysis, the data conversion
	and interface specifications are completed.
